Quick Start — Ubuntu / WSL

Install GCC 14, then compile and run in one step:

sudo add-apt-repository ppa:ubuntu-toolchain-r/test -y
sudo apt update && sudo apt install g++-14 -y

g++-14 -std=c++23 -O3 -march=native \
  -pthread -fno-exceptions -fno-rtti \
  primecover1024.cpp -o primecover

./primecover

Output lines look like:
N=42 prime=181 lines=8 time=0.000s mode=W active=312
Where mode=W = witness hit (instant), R = root closed, D = full branch-and-bound.

Edit kStartN and kExecutionLimit at the top of the file to control the sweep range. For AMD Zen 5, use -march=znver5 for a small extra gain. On Windows, run inside WSL and boost CPU priority with: (Get-Process vmmem*).PriorityClass = 'High' in an elevated PowerShell.
